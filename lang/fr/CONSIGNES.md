# SNK vs. Capcom - Card Fighters 2 Expand Edition — consignes de traduction française

Ces consignes ont servi à toute la traduction ; elles valent aussi pour une relecture ou une correction.

## Le jeu
Jeu de cartes à collectionner (cartes de personnages SNK et Capcom). Le héros, **Rikuto** (リクト, nom
choisi par le joueur : variable `{10}`), collégien de l'école **CF** (CFスクール), membre du minuscule
**club de cartes** (カード部) avec sa cadette **Haruna**. Un voleur masqué, **Neomanto** (ネオマント),
dépouille les joueurs de leurs cartes ; un robot, **Robomanto** (ロボマント), lui a volé les siennes.
La directrice, **Mme Lip** (リップ先生), leur confie l'enquête. Ton : comédie légère et énergique,
répliques courtes, gags, rivalités de cour d'école, personnages hauts en couleur avec des tics de langage.

## Source : le JAPONAIS
La traduction anglaise existante est un travail amateur, plein de contresens. Le sens, le ton et les
détails viennent du japonais ; l'anglais ne sert qu'à lire un kanji douteux.

## Personnages et tics (d'après le japonais)
- **Rikuto** `{10}` (オレ) : garçon vif, un peu fanfaron.
- **Haruna** (ハルナ) : cadette pétillante, parle en traînant (ですぅ, まぁす), parle d'elle à la 3e personne
  (« Haruna va… »). Appelle Rikuto « {10} senpai ».
- **Mme Lip** (リップ先生) : directrice et conseillère du club, maternelle, minaudière (わね, のよ).
- **Torawo** (トラヲ), **Asou** (アソウ), **Dogou** (ドゴウ) : le « trio d'idiots » (三バカトリオ) du toit.
  Torawo parle en voyou ; Asou (une FILLE) est laconique et sèche ; Dogou, sbire geignard, finit ses
  phrases par でゲス → « …, hein ! » à chaque fois que le japonais l'a ; il appelle Torawo « patron » et le
  vouvoie.
- **Robomanto** : ロボ → « …, robo ! ».
- **Fuwa** (フワ) : ninja (でゴザル, せっしゃ) → langage d'antan.
- **Yashichi** (ヤシチ) : « élève de 1re année » timide et polie, qui vouvoie Rikuto ; accords au féminin.
- **Fou Gotton** (フォウ) : adulte, アル/ネ → « …, aru ! » (ou « …, ne ? »), français correct par ailleurs ;
  « Aïyaa » pour あいやぁ. Rikuto la vouvoie.
- **Nanako** (ナナコ) : だわさ/のよさ → « …, wassa ! ».
- **Kido** (キド, gérant de la boutique Joy Joy) : gros rire « Wa ha ha ! » ; lui et Rikuto se tutoient.
- **Kei** (accent du Kansai) et **Shin** : adultes du C.O.F, familiers et vifs ; les élèves les vouvoient.
- **Comet** : dame distinguée, proverbes rendus par des équivalents français. **Sys** : hautain.
  **Cap** : froid, « Hmf… ». **Zet** : dandy, dit « Honey » à Haruna. **Neomanto** : pompeux, dit « {10}-kun ».
- Locuteurs : 女の子 → `Fille`, ナレーション → `Narration`, トレードマシン → `Machine d'échange`,
  通信リクト → `Rikuto (câble)`, ????? → `?????`.

## Registre
- **Adapter, pas traduire** : chaque boîte doit se comprendre seule et sonner comme un Français qui parle.
  Pas de calque, pas d'ordre de mots bizarre.
- Le registre suit le japonais : familier si le japonais l'est (« t'as », « y a », avec mesure), sinon
  français standard et correct (« ne » de la négation, « il y a », « il faut »).
- **Tu/vous comme dans les traductions françaises de manga** : un cadet poli (です/ます) VOUVOIE son senpai ;
  élèves du même rang : tutoiement ; élève → adulte : vouvoiement ; adulte → élève : tutoiement ; inconnus
  polis : vouvoiement. Haruna vouvoie Rikuto, Rikuto la tutoie. Haruna parle poliment : grammaire complète,
  jamais « t'es pas », « faut », « c'est pas ».
- Suffixes : « senpai » gardé ; -san/-kun/-chan gardés s'ils sont dans le japonais ; 先生 après un nom →
  « Mme Lip » / « M. X ».
- Onomatopées et cris à la française (« Hein ? », « Aïe ! », « Mwa ha ha ! »).

## Termes du jeu
カード = carte ; デッキ = deck ; 山札 = pioche ; 手札 = main ; 捨て札 = défausse ; 場 = terrain ;
キャラ(カード) = (carte) personnage ; ACカード = carte Action (AC) ; REカード = carte Réaction (RE) ;
援護 = renfort ; 応戦 = parer ; 攻撃 = attaque ; 合体攻撃 = attaque combinée ; 硬直 = figé (硬直解除 = dégel) ;
能力 = capacité (icônes `{1EC}` `{1ED}` `{1EE}` recopiées devant « capacité ») ; BP, SP inchangés ;
HP = PV ; 先攻 / 後攻 = premier / second joueur ; ターン = tour ; フェイズ = phase ; レアリティ = rareté ;
トレード = échange ; トレードマシン = machine d'échange (menu « Échanges ») ; ダウジングマシーン = détecteur
de cartes ; 通信デスマッチ = Match à mort ; 通信エキシビジョン = Match amical ; 対戦 = duel ;
パワーアップ = renforcé ; うる / かいとる (boutique) = vendre / racheter ; カード部 = club de cartes ;
部室 = local du club ; CFスクール = l'école CF ; 理事長 = directrice ; 大会 = tournoi.
Noms gardés en japonais : Neomanto, Robomanto, Gemanto, Gemanto Lady (G. Lady).
激究三人組 = Trio Explosif ; 三バカトリオ = trio d'idiots ; イジゲンデッキ = deck venu d'une autre dimension.
Lieux : MV Land, Powered Lab, VS. Entertainment, parc Joyful, boutique Joy Joy, Hyper New Town,
Card of Fighters (C.O.F), le CP (paquebot), l'église Rooster, la salle des duels.
Séries : noms occidentaux officiels (Street Fighter, Fatal Fury, Samurai Shodown, Rival Schools, The Last
Blade, Darkstalkers, Art of Fighting, Mega Man, Resident Evil, Red Earth…) ; « 〈Série X〉 » → `<X>`.
Personnages SNK/Capcom : nom officiel occidental (Kyo, Ryu, Nakoruru, Chun-Li, Terry Bogard…).

## Format (vérifié par `tools/controle.py`)
`lot_NN_fr.tsv` : `index <TAB> texte`, une ligne par index, UTF-8, mêmes index que `out/src/lot_NN.tsv`
(produit par `tools/extraire.py`). Pas de tabulation ni de vrai retour à la ligne dans le texte.

- `D` (dialogue) : le japonais est présenté en boîtes séparées par ` ¶ ` (`⏎` = retour à la ligne japonais).
  Écrire chaque boîte d'un seul tenant et séparer les boîtes par ` ¶ ` : le build coupe les lignes au pixel
  près (136 px) et ajoute des boîtes si besoin. `\n` force un retour à la ligne voulu.
- `F n` (fenêtre fixe) : au plus `n` lignes séparées par `\n`, 136 px par ligne. Cartes (2001-2999) :
  3 lignes ; textes d'ambiance (2501-2999) : 3e ligne = série entre `< >`.
- `N` (nom de locuteur) : 80 px au plus.
- `M` (menu, colonnes) : recopier les codes `{M ..}` `{I ..}` à l'identique ; `@` = case vide d'une tuile
  (alignement) : garder les colonnes du japonais ; un libellé ne doit pas être plus large que le japonais.
- Lexique (3100-3199) : coupé aux mots par le build.
- `lot_25_fr.tsv` (noms des cartes) : `carte <TAB> nom <TAB> capacité`, 15 caractères au plus chacun ;
  le nom tient en 55 px (face de la carte).

Codes à recopier tels quels : `{08 xx}` (locuteur), `{10}` `{11}` (noms des joueurs), `{12}` (carte),
`{13}` (capacité), `{14}` `{15}` `{18}` `{19}` (nombres, deck, paquet), `{0C}` `{0D}` `{09}` `{0A}` (choix,
attentes), `{1EC}` etc. (icônes). Un code à 3 chiffres au milieu d'un mot japonais est un kanji non
identifié : le deviner, ne pas le recopier.

Caractères : lettres, chiffres, espace, `. , ; : ! ? ' " - ( ) / + = % & * < > [ ] # ~ … « »` et
é è ê ë à â î ï ô û ù ü ç œ É È Ê Ë À Â Ô Î Ù Û Ç Œ. `@` est réservé à l'alignement des menus.
Ponctuation française : espace avant `? ! : ;` et à l'intérieur des « » ; les 「…」 japonais → « … ».
